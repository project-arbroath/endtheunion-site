<p class="intro-text">It's not as hard as you think. We don't need a 'gold standard' referendum granted by the UK government. In fact, we don't need to ask anybody for permission.</p>

<p class="intro-text">All we need say is that we no longer want to be part of the UK. That being in this Union doesn't work for us. So we're leaving. And that's it. That's all we need to do.</p>
